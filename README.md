# Programas Básicos em COBOL

Repositório dedicado ao estudo e prática da linguagem COBOL.

## Programas Incluídos

* **`main.cob` / `hello.cob`**: Programa inicial para exibição de mensagem no terminal.
* **`comovai.cob`**: Programa interativo para leitura de nome e exibição da data formatada.
* **`imc.cob`**: Calculadora de Índice de Massa Corporal (IMC) que recebe a altura e o peso do utilizador e realiza o cálculo matemático.

## Como Executar

Estes programas podem ser executados localmente usando o **GnuCOBOL** ou em compiladores online como o **JDoodle**.

> **Nota para execução interativa (JDoodle):** Ativa sempre a opção **INTERACTIVE** no painel de opções para permitir a introdução de dados via `ACCEPT`.
